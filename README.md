DeepSeek Pilot 是独立开发的第三方扩展，与 DeepSeek 官方无隶属关系。

## 项目进度

当前版本为 **0.9.0 早期开发版**，已实现以下能力：

| 模块 | 当前已实现 |
| --- | --- |
| 项目管理 | 项目树、常驻的新建项目与设置按钮、手动移动会话、置顶、归档、项目内新建会话 |
| 跨会话记忆 | 分开整理个人与项目记忆，在新会话首条消息中带入适用背景 |
| 记忆管理 | 按类别查看与编辑、固定条目、导入导出、个人记忆压缩和本地快照 |
| 长对话接续 | 按配置的上下文预算切换到新会话，带入适用记忆继续对话 |
| 任务管理 | 串行队列、暂停、失败提醒、重试和草稿保留 |
| 清理保护 | 区分插件辅助会话与手动收纳记录，保护来源不明及运行任务关联会话 |

自动会话归类目前关闭，请手动移动会话。记忆仅在普通会话首条消息带入，项目记忆还需选中项目并提前开启；中途开启不会补发。新会话不会强制先选项目，未选项目时按个人记忆规则正常发送。只有附件没有文字时按原生发送，本轮不注入记忆。“聊天显示”可分别控制个人记忆、项目记忆、项目会话消息下方的 token 与时间信息，以及侧边栏自动化会话分组；后两项默认开启。显示开关只控制可见性，不代表停止发送或学习记忆。上传附件并附带文字时，附件卡片独立保留，消息时间、token 和记忆显示按正文匹配。

侧边栏的自动化会话每次打开页面默认收起，展开后显示最近五条；没有归入项目的普通会话列在「未归类会话」中。显示数量不改变会话保留与清理规则。

侧边栏以 DeepSeek 当前返回的会话列表为准，本地按会话 ID 保存项目归属。关闭插件期间删除的会话不会因本地旧缓存再次出现；新 ID 显示在未归类会话中。较早的会话可点「加载更多会话」按官方分页加载，暂未加载的会话仍保留其项目归属。记忆整理与长对话续接使用的历史缓存不会补进侧边栏列表。新建会话在确认创建后立即显示，无需刷新页面。

个人记忆以长期偏好、回答风格和协作习惯为主。事件仅保留对长期生活、职业或以后协作有影响的重要事项，用一两句概述关键结果，不保存日常琐事和详细经过。后续整理与压缩也会筛选已有非固定事件条目；人工固定条目仍受保护。

每轮回答完成后自动整理记忆，包括最新会话；只处理本次官方列表已确认存在、历史完整且尚未整理或内容变化的会话。修改一个会话不会连带重整其他会话，残留待处理记录也不会重发已完成版本。「整理当前会话」仅处理所选会话；个人或项目范围的「更新记忆」仍可主动重整对应范围。尚未加载的历史页需先加载更多，项目归属始终保留。

长对话续接在开启项目记忆、达到上下文预算时，把本轮问题、适用记忆及近期进展发送到同项目的后继会话。确认新会话收到消息后才清空匹配的原草稿；等待期间每 30 秒核对后继会话的历史并回报心跳，只有回答明确完成才结束任务。异常保留原始输入供核对。

设置页定时刷新会保留未变化内容的文字选区。记忆整理从实际发送请求取得辅助会话 ID，每 5 秒检查页面状态，最多每 30 秒固定核对该会话的历史完成状态，不依赖页面出现回答文字；仍在生成或内容继续变化时持续等待，连续 10 分钟无生成状态、无内容进展且未确认完成才报告停滞，并显示目标会话及最近的历史读取错误。辅助会话在首次识别时登记为插件会话，避免触发普通会话的重复整理。

## 安装方式

### 方式一：下载 ZIP（推荐）

在[仓库主页](https://github.com/5J-5J/DeepSeek-Pilot)点击 **Code → Download ZIP**，下载后解压到一个固定目录。目前通过源码加载安装，不需要编译。

### 方式二：Git 克隆

```sh
git clone https://github.com/5J-5J/DeepSeek-Pilot.git deepseek-pilot
cd deepseek-pilot
```

### 在 Chrome 中加载

1. 确认解压或克隆后的目录中存在 `core/manifest.json`。
2. 在 Chrome 中打开 `chrome://extensions/`，开启**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择仓库中的 **`core/`** 文件夹。
4. 打开或刷新 [DeepSeek 网页版](https://chat.deepseek.com/)，使用自己的账号登录。
5. 创建项目并填写目标，将相关会话移入项目；在记忆管理页查看或维护记忆。
6. 在项目内开启新会话，发送首条消息前确认项目记忆开关。

运行扩展无需构建或配置单独的模型 API key。记忆整理等自动化通过 DeepSeek 网页辅助会话执行，需要可用账号与网络，并会产生站点请求。目前扩展界面为中文。

### 在 Firefox 中加载

1. 使用 **Firefox 128 或更新版本**，在地址栏打开 `about:debugging#/runtime/this-firefox`。
2. 点击**临时载入附加组件**，选择仓库中 **`firefox/manifest.json`**（不要选 `core/manifest.json`）。
3. 打开或刷新 DeepSeek 页面；如果扩展未获站点访问权限，在扩展菜单允许访问 `chat.deepseek.com`。

`firefox/` 已包含完整文件，无需构建。临时扩展在浏览器重启后需要重新加载；固定扩展 ID 用于保持同一身份，但仍建议导出重要记忆备份。Chrome 和 Firefox 的本地数据分别保存，需要迁移时使用记忆导出、导入。普通正式版 Firefox 的长期安装需要 Mozilla 签名的 XPI，当前仓库未提供签名包。

更新后，在上述调试页点击扩展的**重新载入**，再刷新 DeepSeek 页面。此版本使用事件后台与 Firefox Promise API；目前通过离线模拟验证，真实账号功能尚未在 Firefox 验证。

### 更新已安装的扩展

Git 安装在仓库目录执行 `git pull --ff-only`；ZIP 安装将新源码解压到原安装位置。然后在 `chrome://extensions/` 找到 **DeepSeek Pilot**，点击重新加载，再刷新 DeepSeek 页面。不要删除已加载的目录；更新前可先导出重要记忆，不必卸载扩展。

如果提示找不到 manifest，请确认选择的是包含 `manifest.json` 的 `core/`，而不是 ZIP 文件或仓库根目录。

### 使用须知

记忆和同步数据保存在本地，但记忆带入、整理与压缩会向 DeepSeek 发送相关内容。插件生成的辅助会话保留最近 10 条，符合条件的更早记录会从 DeepSeek 删除；手动收纳记录受到保护。本地会自动清理 30 天前的已完成作业、90 天前的耗时指标，以及已删除会话在 7 天后的消息和归属记录。删除项目不删除远端聊天，清除扩展数据则会清除本地记忆及快照。

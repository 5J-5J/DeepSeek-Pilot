# DeepSeek 任务工作台

插件用任务列表替换 DeepSeek 原版左侧栏，并在选中任务时显示独立的右侧任务详情栏。聊天区、输入框、附件、模型选择和生成流程均保持原版。

## 当前功能

- 从原版侧栏读取真实会话；
- 新建、重命名、折叠和删除任务；
- 通过会话右侧 `•••` 将会话移动到任务；
- 从任务中移除会话；
- 点击会话继续打开原版 DeepSeek 对话；
- 使用 `chrome.storage.local` 保存任务和会话归属；
- 从会话菜单直接打开 DeepSeek 原版管理菜单，继续使用重命名、置顶、分享、多选和删除；
- 一键切回 DeepSeek 原版侧栏。
- 左侧任务卡不再展示记忆入口；点击任务名称后在右侧查看任务详情；
- 右侧栏展示整理状态、任务进度、约束/决定/阻塞统计、任务会话和下一步；
- 可直接编辑概况和下一步，添加、修改、固定、推进或退役结构化记忆条目；
- 可一键复制任务上下文，或打开该任务最近的 DeepSeek 会话；
- 为每个任务维护结构化任务记忆：概况、下一步、目标、约束、决定、里程碑和阻塞；
- 维护跨任务用户事实：非敏感资料、稳定偏好、工作方式和术语，可人工编辑或禁用；
- 从任务菜单启动独立的 DeepSeek 整理请求，读取任务内会话原文并生成记忆更新；
- 对整理结果执行 JSON、作业版本、会话归属、枚举和来源证据校验，失败时保留旧记忆；
- 人工固定的任务条目不会被模型覆盖，禁用的用户事实不会因重整旧历史而自动复活。

删除任务只会解除本插件中的归类；任务中的 DeepSeek 会话不会被删除，而是回到“未分类会话”。

## 记忆更新如何工作

在任务的 `•••` 菜单中点击“用 DeepSeek 更新记忆”。插件会在任务会话页面通过 `/api/v0/chat/history_messages` 读取完整消息历史；只有历史接口不可用时才回退到页面 DOM。随后它会在一个非激活标签页中发起 DeepSeek 整理请求。页面输入框只放入带随机 ID 的一次性标记；MAIN world 网络钩子在 `/api/v0/chat/completion` 或 `/api/v0/chat/edit_message` 出站前，直接把请求体中最后一条用户消息替换为完整整理上下文。DeepSeek 只返回受约束的 JSON；插件本地校验通过后才提交新版本。

请求体改写采用一次性指令并校验随机标记。未携带匹配标记的正常用户请求不会被修改；改写失败时也不会把完整上下文回填到页面输入框。`fetch` 和 `XMLHttpRequest` 两条请求链均受支持，原请求的 headers、credentials、signal 等参数会被保留。

记忆保存在 `chrome.storage.local`，但整理输入会发送到 DeepSeek，并可能在 DeepSeek 历史中留下一个维护会话。首次使用时插件会明确提示这一点。浏览器标签页会在整理完成后关闭，远端会话不会被插件偷偷删除。

当前版本为避免隐性信息丢失，不会静默截断超长整理输入；任务原文累计超过 50000 字符或完整整理提示超过 60000 字符时，会保留旧记忆并提示失败。历史接口不可用且只能回退到 DOM 时，未呈现的懒加载消息仍会被标记为不完整采集。

## 本地加载

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `codex-task-plugin`。
5. 刷新 `https://chat.deepseek.com/`。

## 离线自检

```powershell
node .\codex-task-plugin\memory-test.mjs
node .\codex-task-plugin\request-body-test.mjs
node .\codex-task-plugin\history-test.mjs
node .\codex-task-plugin\visual-test.mjs
```

前三个脚本分别验证记忆合并、请求体改写和历史接口响应解析。最后一个脚本会使用本机 Chrome 和已保存的 DeepSeek 页面，验证侧栏挂载、会话读取、任务与记忆界面、会话移入/移出和原版管理入口，并生成 `preview.png` 与 `preview-inspector.png`。

## 页面改动边界

插件界面统一挂在 `#dtw-root`。原版侧栏仅增加 `dtw-native-sidebar-covered` 类，通过 `visibility: hidden` 隐藏但保留其布局；切换回原版侧栏时移除该类。右侧详情栏以可关闭的浮层呈现，不修改 DeepSeek 主内容区结构。

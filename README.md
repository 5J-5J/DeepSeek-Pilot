# DeepSeek 项目工作台

扩展入口是 `core/manifest.json`。在 `chrome://extensions/` 开启开发者模式，加载 `core` 文件夹，再刷新 DeepSeek 页面。

插件将 DeepSeek 会话显示为「项目 → 会话」树。每个项目和“未归类”内按最新消息时间排序；旧会话可手动移入项目，新会话首轮完成后可以自动归类。原生会话节点保留在 DOM 中，导航和菜单复用 DeepSeek 原生操作。删除项目只解除插件归属，不删除远端会话。

侧栏采用文件夹图标和缩进会话行，点击项目整行平滑展开或收起；折叠状态按账号保存在本地，后台刷新不重建内容未变的树。悬停或键盘聚焦时显示项目菜单和新建会话按钮。项目菜单在行旁打开，支持重命名、目标编辑、置顶和归档；在项目内新建会话后，首条发送沿用现有项目归属和记忆流程。会话菜单直接复用 DeepSeek 原生菜单，并追加移到项目、从项目中移除及自动化收纳入口；原生历史尚未挂载的会话保留插件菜单和打开会话入口。支持深浅主题、键盘菜单操作和系统减少动效设置。

打开会话前检查服务端记录；只有明确返回不存在才移除本地记录。网络故障、登录过期和空会话不会被当作删除。原生删除同时兼容 fetch、Request 和 XHR。

启动时及 DeepSeek 页面可见期间每 5 分钟同步本地已登记会话的远端状态，包含记忆起始时间之前的会话和自动化会话。先核对登录账号，再逐段查询历史接口；确认不存在后标记本地删除、清除待处理引用并取消来源已删除的未完成任务，不再次删除远端会话。已删除会话不重试，也不计入“未能读取”；临时错误保留记录并显示首个失败原因。只对记忆范围内的普通会话继续记忆更新，空会话保留。

自动化会话默认只展示最近 10 条。DeepSeek 页面打开时每分钟清理更早的自动化会话，通过网页原生删除接口真实删除远端会话，成功后同步本地状态；正在执行任务的会话暂缓清理，失败保留记录并在下一次检查重试。清理前核对登录账号，普通用户会话不参与清理。

## 记忆更新

开启新会话后，之前的普通会话成为旧会话。系统按会话创建时间从早到晚处理，最新普通会话不参与更新，自动化会话除外。创建时间相同时用会话 ID 保持确定顺序。起始时间默认是插件首次运行时间，可在设置页修改；只处理该时间之后创建的会话，创建时间未知或完整分支尚未同步时暂不处理。

每次请求只处理一个完整旧会话，个人和项目分别使用不同提示词：

- 个人：个人提示词＋现有个人记忆＋待处理会话，关注用户明确表达或确认的稳定资料、长期偏好、工作方式和术语。助手仅提供上下文；一次提问、转贴资料、角色扮演、替他人咨询和项目临时进度不作为个人事实。
- 项目：项目提示词＋项目设置中的目标说明＋该项目现有记忆＋该项目待处理会话，关注目标、约束、决定、进展、阻塞和下一步。明确区分候选建议、已确认决定、执行结果及验证状态。

模型返回更新后的完整记忆列表。已有 ID 可以保留或修改，空 ID 表示追加，从列表省略的旧条目表示删除。提示词允许追加、修改、合并、删除，不要求模型提供证据或逐字引用，也没有原话证据校验。人工固定条目必须原样保留。个人生效记忆正文合计限制在 5000 字内。

个人整理提示词参考 [Mem0 的用户事实提取和记忆更新规则](https://github.com/mem0ai/mem0/blob/main/mem0/configs/prompts.py)、[官方定制指南中的正反例设计](https://docs.mem0.ai/open-source/features/custom-instructions)及 [Letta 的字符容量设计](https://docs.letta.com/v1-sdk/memory/memory-blocks)，按本插件的分类及完整列表协议编写。语义重复不追加，明确更正更新旧条目；未再次提到的有效旧记忆继续保留。示例仅展示规则，不是待保存的数据。提示词显示当前正文和固定正文用量，5000 字额度覆盖已有与新增的全部 content，计正文内标点、空格及换行，不计 JSON 外壳、ID、类别或 token。接近上限时去重、精简并按长期价值取舍，目标约 4000 字；字数仍由程序校验。

项目整理提示词参考 [Cline Memory Bank 的项目概况、设计约束、当前工作和进度划分](https://docs.cline.bot/best-practices/memory-bank)，以及 [Graphiti 的重复与冲突判定规则](https://github.com/getzep/graphiti/blob/main/graphiti_core/prompts/dedupe_edges.py)，按现有七类条目整理，不要求创建外部文件。保留决定依据与适用条件，明确的状态变化同步更新进展、阻塞和待办；不同版本或阶段的事实不能因为更新更近而被误判为冲突。未采纳建议不当作决定，只有助手口头声称完成且缺少可核对结果时标为待核验。未再次提到的有效旧内容和人工固定条目继续保留，完整列表仍沿用现有 ID 与 JSON 协议。

个人记忆正文达到 5000 字时，自动开启独立 DeepSeek 会话压缩，专用提示词要求合并重复、精简措辞，保留关键事实、偏好、数量及否定关系，目标约 4000 字且必须少于 5000 字。固定条目保留 ID 和全部事实，允许精简措辞。旧会话更新的超限结果先压缩再保存；导入或历史记忆超限时保留所有原文，等待压缩完成，不自动停用。手动编辑超限时启动现有记忆压缩，并提示完成后重新保存编辑内容。

压缩时依据明确记录的使用者身份、主要职业、经常从事的工作和长期习惯判断价值，优先保留对未来协作有用的资料、偏好、工作方式和限制，允许主动放弃一次性请求、过时内容、重复例子及与主要工作关联弱的非固定细节；不猜测身份或使用频率。人工固定条目不能删除。其余条目均无长期价值时允许清空。

压缩遵循队列暂停和并发限制；重复刷新不重复建任务。结果保存前校验字数、条目 ID、固定条目和记忆版本，原记忆被修改或删除时不接受旧结果。失败保留原记忆，可在设置页重试或忽略；有效压缩结果保存失败时复用结果重试保存。

系统不再按问答轮数触发更新，也不再提供轮数阈值设置。已登记会话未变化时不扫描、不校验，启动和定时刷新也不全量读取历史。优先接收用户操作时原生页面已有的历史与删除响应；新增消息或分支变化时，只对对应会话补读一次。仅标题或时间变化不触发历史读取。旧会话确实变化后，从变化的会话开始重放后续会话的本地记忆任务，避免旧事实覆盖较新的决定。

记忆管理区始终保留“更新记忆”入口。选择个人范围只更新个人记忆，选择项目只更新该项目；主动更新会重新处理对应范围内已同步的旧会话。

记忆更新顺序执行，每次出队读取最新记忆。前序会话失败时保留失败记录并跳过，后续任务继续；主动重试前序会话后，后续会话按顺序重放。有效结果保存失败可以直接复用，不重复请求模型。取消等待任务跳过该会话本次更新；内容再变化或用户主动更新后仍可处理。完整提示超过 60000 字符时保留旧记忆并报错，不拆成独立问答或静默截断。

记忆增删、会话处理版本、待处理列表和任务完成状态在同一 IndexedDB 事务保存。写入前检查会话版本、项目归属和记忆版本，运行期间来源变化的结果不能覆盖当前数据。

旧版证据字段和轮数设置在迁移时清除；旧整理请求取消，已有记忆保留，旧会话按新流程重新处理。扩展已经不加载的旧后台、内容脚本、证据领域模块及文件夹管线已删除；原 `chrome.storage.local` 项目和记忆的数据迁移入口保留。

## 发送、设置与保护

普通会话仅在首条消息自动带入生效个人记忆；“项目记忆”按钮开启且已选项目时，同时带入该项目的目标和生效记忆。两类记忆都只带入一次，后续消息、刷新或重新打开会话不重复，中途开启项目记忆也不补发。附带资料按“个人/项目 → 类别 → 条目”分组，类别顺序与管理页一致，并用两句话说明附带范围、背景用途和应回答的本轮问题；用户原始问题单独放在 `<current_question>` 中。个人记忆无需先选择项目。接续到新的会话时，新会话首条消息重新带入个人和项目记忆，后续不重复。未确认的发送不会提前消耗首条机会。自动化会话不注入个人或项目记忆。显示个人记忆和显示项目记忆开关只控制页面可见性，不改变实际发送内容。上下文预算、接续提醒和回答预留共同控制长会话接续；没有服务端 token 数据时按正文长度保守判断，不显示伪造 token 数。

插件必要的历史读取和清理按账号间隔至少 1 秒，同一页面对同一会话的并发读取合并。打开会话不增加预先校验，复用本地历史并接收原生页面响应。自动化生成期间只检查页面和本地状态，回复稳定后最多补读一次结果。限流后该账号的插件主动读取、自动清理和新自动化任务统一冷却 60 秒，重载后台仍保留冷却状态。登录失效后立即停止主动请求并通知用户，只接收原生页面重新登录后的有效账号响应；不调用账号/登录接口，不猜测 token、不切换认证方式重试、不重复发送消息。账号受限时停止插件请求，用户确认原生聊天已恢复后，可在设置中恢复任务。

发送记忆时，每个类别只显示一个类别标签，下方条目按 1、2、3 编号，各类别从 1 开始，条目不重复附带标签。聊天显示按该轮消息实际发送的记忆过滤，保留范围、类别和条目层级，同时兼容旧版 `[个人]` 和 `[个人/类别]` 标签。原生气泡只包含用户问题时，在消息旁显示“本轮带入的记忆”；切换显示开关同步更新对应范围，保留原生消息和复制等操作。

编辑历史消息时，修改框里的个人记忆和项目记忆也跟随对应显示开关，切换时保留正在修改的问题。隐藏只影响显示；提交编辑时保留这条消息原来附带的隐藏记忆，显示出来的记忆可以随问题一起修改，不读取最新记忆重新注入。取消或关闭编辑后清除临时编辑上下文，原生消息恢复或文字重写时在浏览器绘制前按当前设置过滤记忆，普通新消息不受影响。

归类、记忆更新、压缩和接续共用串行队列，全局一次只运行一个任务，切换账号也不会增加并发。接续等待回复完成才释放队列。失败或超时的任务跳过，原始草稿与失败记录保留；侧边栏设置按钮显示红点，设置页持续显示红色提醒，可查看、重试或忽略未完成任务。暂停队列同时暂停新任务、后台补读和自动清理；正在运行的任务完成收尾，用户正常聊天继续。归类与接续任务可以调序，记忆任务保持会话顺序。自动化会话仍保留最近十个，仅在队列空闲且列表变化时清理多余会话，清理失败不循环重试。

DSW 原生输入框变成可见禁言提示时，插件立即按账号保存受限状态，停止自动化任务、接续发送、主动历史读取和清理请求；刷新页面或重启后台后仍暂停。检测排除聊天正文、侧栏会话标题及插件自己的提示。解除禁言后，可在设置页手动恢复请求；页面仍显示禁言时会继续阻止发送。

记忆按类别展示，可编辑整类、导入、导出和批量删除。每个账号保留最近五份本地快照，自动恢复缺失、损坏或版本回退的条目。自动记忆恢复检查会话内容版本及项目归属，不验证原话证据；无可用会话版本的旧条目不自动恢复。

用户主动删除会记录删除意图并清除快照中的对应内容，防止再次自动学习同样的内容。模型删除会清除条目及快照中的对应记录，之后新会话仍可以重新建立该事实。人工新增或导入可以重新保留用户主动删除的内容。整个扩展数据被清除后，本地快照也会丢失，需要事先导出的文件恢复。

```text

core/page/page-network.js        网络钩子
core/options/                   设置页
core/manage/                    记忆管理
tests/                         自检与浏览器测试
docs/                          设计文档
```

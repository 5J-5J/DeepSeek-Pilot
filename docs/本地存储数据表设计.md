# DeepSeek 任务工作台：最小本地数据表

版本：v0.2｜2026-09-24
实现：Chrome 扩展 IndexedDB；一张“表”对应一个 object store

本文件只规定基础功能需要保存的数据。可沿用现有项目的数据层，只要能表达这些字段和关系。DSW 抓包字段见 [api-recon-schema.md](api-recon-schema.md)；没有实际返回的字段保持空值。

## 通用规则

- 所有主键以 accountId 开头，来自 DSW 当前用户 ID；账号不明时暂停项目自动操作。
- 本地时间统一为 Unix 毫秒。DSW 的 Unix 秒浮点在入库时转换为毫秒。
- sessionId 是 DSW 会话 ID。messageId 只在某个会话内唯一；当前分支从 sessions.currentMessageId 沿 messages.parentId 回溯。
- 不保存 DSW 登录令牌、设备指纹、PoW 挑战或 SSE 原始流。

## 1. sessions：DSW 会话镜像

主键：[accountId, sessionId]；索引：[accountId, purpose, updatedAtMs]。

| 字段 | 类型 | 用途 |
|---|---|---|
| accountId、sessionId | string | 稳定身份 |
| purpose | USER / CLASSIFY / MEMORY / AUTOMATION | 区分用户会话、插件作业会话及手动收纳的旧自动化会话，避免递归归类 |
| title、titleType | string / null | DSW 标题及其状态 |
| currentMessageId | number / null | 当前分支末端 |
| updatedAtMs、lastMessageAtMs、lastKnownMessageId、seenAtMs | number / null | DSW 更新时间、排序用的最新消息时间及消息 ID、本地采集时间 |
| deleted | boolean | DSW 明确删除后才设为 true |

标题以 DSW 为准；项目名不写入此表。首版还把 DSW 原生侧栏已经加载的历史会话登记为 USER，默认放入“未归类”；旧消息只在用户打开对应会话后按需采集。

## 2. messages：必要的 DSW 消息

主键：[accountId, sessionId, messageId]；索引：[accountId, sessionId, parentId]。

| 字段 | 类型 | 用途 |
|---|---|---|
| accountId、sessionId、messageId | string、string、number | 消息身份 |
| parentId | number / null | 当前分支回溯及编辑分叉 |
| role、status | string | USER / ASSISTANT、完成状态 |
| insertedAtMs | number / null | DSW 消息日期 |
| accumulatedTokenUsage | number / null | DSW 返回的分支累计 token；缺失就不显示 |
| fragments | array | 每个元素含 fragmentId、type（REQUEST / RESPONSE / THINK）、content；可选 elapsedSecs |
| originalInput | string / null | 插件发送前保存的用户原文；整理时优先使用，避免把补入记忆当作用户要求 |
| seenAtMs | number | 本地采集时间 |

只用当前分支的完整消息做记忆和接续。THINK 的 elapsedSecs 不是总等待时间。用户原文取 REQUEST，回答取 RESPONSE。

## 3. projects：本地项目

主键：[accountId, projectId]；索引：[accountId, archived, updatedAtMs]。

| 字段 | 类型 | 用途 |
|---|---|---|
| accountId、projectId | string | 项目身份；projectId 由插件生成 |
| name | string | 用户可改的项目名 |
| systemKind | "AUTOMATION" / "PERSONAL" / 空 | 内部收纳或个人记忆待整理队列；不参与用户项目树 |
| goalShort | string / null | 归类时提供给 DeepSeek 的简短目标 |
| archived、pinned | boolean | 本地项目排序与归档 |
| currentSessionId | string / null | 默认继续工作的会话 |
| createdAtMs、updatedAtMs | number | 本地时间 |
| pendingTurnRefs | array | 已完成但尚未整理的问答来源（sessionId、assistantMessageId） |

普通项目改名只改本地，不改 DSW 标题。AUTOMATION 收纳项目只展示 CLASSIFY/MEMORY 会话；PERSONAL 系统记录保存跨项目待整理轮次。两者都不能作为用户会话的目标项目。

## 4. memberships：会话项目归属

主键：[accountId, sessionId]；索引：[accountId, projectId]。

| 字段 | 类型 | 用途 |
|---|---|---|
| accountId、sessionId | string | 对应 USER 会话 |
| projectId | string / null | 一个会话最多一个项目；null 为未归类 |
| source | NONE / AUTO / MANUAL / ROLLOVER | 归属来源 |
| manualLock | boolean | 用户手动移动或移出后，自动归类不能覆盖 |
| memoryModeEnabled | boolean | 此会话的“项目记忆”按钮状态 |
| updatedAtMs、version | number | 本地修改时间与防旧结果覆盖版本 |
| countedTipIds | number[] | 已计入项目待整理轮次的助手消息 ID，防止刷新重复计数 |
| countedPersonalTipIds | number[] | 已计入个人记忆待整理轮次的助手消息 ID |

CLASSIFY、MEMORY 和 AUTOMATION 用途的会话不进入此表。建议新项目时，待用户确认后才创建 projects 记录并更新 memberships。

## 5. memories：个人与项目记忆

主键：[accountId, memoryId]；索引：[accountId, scope, projectId, state]。

| 字段 | 类型 | 用途 |
|---|---|---|
| accountId、memoryId | string | 记忆身份 |
| scope | PERSONAL / PROJECT | 个人或项目记忆 |
| projectId | string / null | PROJECT 必填，PERSONAL 为空 |
| kind | string | 目标、约束、决定、进展、阻塞、下一步、偏好等 |
| content | string | 记忆正文 |
| state | ACTIVE / CANDIDATE / DISABLED / STALE | 生效、候选、停用或来源失效 |
| pinnedByUser | boolean | 人工固定；自动整理不可覆盖 |
| sourceSessionId、sourceMessageId | string / null、number / null | DSW 来源；导入或手写可为空 |
| version、updatedAtMs | number | 防旧整理结果覆盖与编辑时间 |

手动编辑直接更新内容与 version。来源分支被编辑或会话移出项目时，相关自动记忆设为 STALE，后续不注入。停用项保留，避免旧整理立刻恢复。导入导出以记忆和项目 ID 为核心，不要求首版实现完整修订历史。

## 6. jobs：归类、整理与发送作业

主键：[accountId, jobId]；索引：[accountId, status, updatedAtMs]。

| 字段 | 类型 | 用途 |
|---|---|---|
| accountId、jobId | string | 本地作业身份 |
| type | CLASSIFY / DISTILL / SEND / ROLLOVER | 作业类型 |
| memoryScope | PERSONAL / 空 | DISTILL 的目标范围；空表示项目记忆 |
| status | PENDING / RUNNING / NEEDS_REVIEW / DONE / FAILED | 可恢复状态 |
| sourceSessionId、targetSessionId | string / null | 原会话与新会话 |
| automationSessionId、projectId | string / null | 归类/整理会话与项目 |
| sendId | string / null | 一次发送的固定标识 |
| rawInput、payload | string / null | 原始输入和实际准备提交的正文 |
| inputVersion | number / null | 归属或记忆版本，旧结果不可覆盖新操作 |
| result | object / null | 校验后的 JSON 归类结果或整理结果 |
| turnRefs | array / null | 整理作业覆盖的待更新问答来源，成功后从相应队列移除 |
| createdAtMs、updatedAtMs | number | 本地时间 |

在发送或创建后继会话前先写作业；确认 DSW 收到对应用户消息后标记 DONE。结果不明改为 NEEDS_REVIEW，保留 rawInput，不自动重发。归类会话的结果只允许已有项目、新项目建议、未归类三种；新项目建议待用户确认。

## 7. settings：插件设置

主键：[accountId, key]。

| key | 值 | 说明 |
|---|---|---|
| maxContextTokens | 正整数 | 用户设定的工作预算 |
| warningRatio | 0 到 1 之间的小数 | 接近预算时提示 |
| replyReserveTokens | 非负整数 | 为下一次回答预留 |
| memoryModeDefault | boolean | 新会话的按钮默认状态，默认 false |
| distillEveryTurns | 1–30 的整数 | 项目与个人记忆分别累计多少轮完整问答后自动整理，默认 5 |

DSW 返回的 token 与客户端限额只作参考；本表是用户的插件设置，不覆盖 DSW 设置。

## 8. metrics：本机观测时间

主键：[accountId, metricId]；索引：[accountId, sessionId, userMessageId]。

| 字段 | 类型 | 用途 |
|---|---|---|
| accountId、metricId、sessionId | string | 指标身份与会话 |
| userMessageId、assistantMessageId | number / null | DSW 消息关联 |
| submittedAtMs、firstOutputAtMs、completedAtMs | number / null | 本机实际观测时刻 |
| memoryModeUsed | boolean | 本轮是否使用项目记忆 |

首字等待和总耗时由时间戳计算；历史没有观测值时显示未知。token 直接读取 messages，不在此表重复存储。

## 写入与导入导出

观察到页面已加载的历史会话时写 sessions 和未归类 memberships，不触发自动归类；观察到新会话时写 sessions 和未归类 memberships，消息完成后写 messages，再触发归类或记忆整理。人工移动会话时更新 memberships.manualLock 与 version；自动作业提交前检查 version。新建后继会话并确认发送后，才更新 projects.currentSessionId。导入记忆前预览项目映射和重复 ID；导入不创建、改名或删除 DSW 会话。

IndexedDB 没有外键，读写层需要校验 accountId、projectId 和 sessionId 的对应关系。首版可以按实现需要增加索引或少量字段，不必为了尚未使用的功能建更多表。
